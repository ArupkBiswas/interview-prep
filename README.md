# Interview Prep Repository

This repository is a structured collection of programs, examples, and notes to help with technical interview preparation. It includes hands-on examples and categorized folders for quick reference and revision.

## Folder Structure

```text
interview-prep/
│
├── dsa/                  # Data Structures and Algorithms
│   ├── arrays/
│   ├── linked-list/
│   ├── trees/
│   └── graphs/
│
├── streams/              # Java 8+ Streams API examples
│   ├── basics/
│   └── map-filter-reduce/
│
├── multithreading/       # Multithreading and Concurrency in Java
│   ├── thread-basics/
│   ├── synchronization/
│   └── executors/
│
├── system-design/        # (Optional) System Design Notes and Examples
│
├── designPatterns/             # Common Coding and Design Patterns
│
└── README.md             # You're here!
```
## Overview
|       TOPIC               |               Descripition                                         |
|---------------------------|--------------------------------------------------------------------|
|      `dsa/`               |     Core DSA topics with categorized problems and solutions.       |
|      `streams/`           |     Java 8+ Stream API usage examples and patterns.                |
|      `multithreading/`    |     Java multithreading concepts with code samples.                |
|      `system-design/`     |     (Optional) Notes and examples for system design interviews.    |
|      `patterns/`          |     Coding and design patterns commonly asked in interviews.       |
